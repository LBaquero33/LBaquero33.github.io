Baseball analytics / SportsForce project context

Hitter Damage & Swing Efficiency

I built the scoring, data-processing, validation, and reporting system behind a hitter-development model that separates contact value from swing decisions.

The MLB pipeline contains about 1.25 million raw pitches. A separate college validation set uses rolling-origin holdouts so every test season is predicted only from earlier seasons.

Finding: next-season Damage per Contact was the only target to clear the project’s 2% holdout-improvement threshold; the other projection targets remain provisional or marginal.
