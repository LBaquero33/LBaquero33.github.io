The project

A plan for every count.

The Pitch Sequencer generates count-by-count primary and backup pitch-location options from hitter tendencies and selected pitcher context.

The layout is designed to be read as an attack plan: find the count, see the first option, and keep a second call ready.

This is the pitch-sequencing portion of the broader MLB Attack project.

01

Read the hitter

Use hitter tendencies to frame the locations and pitch types most relevant to the matchup.

02

Fit the pitcher

Keep the plan connected to the selected pitcher rather than using one generic attack pattern.

03

Sequence the count

Present a primary and backup option for the full count matrix in a single scouting view.
