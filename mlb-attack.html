Game planning

What is the plan if the count changes?

The sequencer organizes a matchup plan so the pitcher or coach can find the count, read the first option, and keep a second call ready.

The recommendations are built from hitter tendencies and the selected pitcher’s context. The sheet separates first and second times through the order when the available plan calls for it.

This is a planning aid, not an automated in-game decision. A coach or scout still reviews pitch fit, health, command that day, and the game situation.

How to read it

Inputs and limits stay visible

  • Hitter tendencyFrames the pitch types and locations relevant to the matchup.
  • Pitcher contextKeeps the plan tied to the selected pitcher rather than a generic attack pattern.
  • Primary and backupGives the coach an alternate call without leaving the count matrix.
  • LimitationThe report does not know game-day feel, fatigue, injury, or unexpected command changes.
