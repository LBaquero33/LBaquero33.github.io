Baseball analytics / hitter evaluation

Hitter Damage & Swing Efficiency Model

An end-to-end system for measuring how efficiently hitters convert swing opportunities into damage.

Built with
R, Shiny, Python, TrackMan, MLB Statcast
Scale
1.25M+ MLB Statcast pitches
Calibration
673 completed-season MLB hitter profiles

The project

Damage, with the process attached.

The model evaluates how efficiently hitters turn swing opportunities into damage using exit velocity, launch angle, contact quality, swing decisions, pitch characteristics, and situational context.

Resumable data pipelines standardize college TrackMan/Savant and MLB Statcast pitch-level data, run quality audits, and produce player-season summaries and reproducible analysis outputs.

A transparent exit-velocity × launch-angle Damage Score sits alongside pitch type, velocity, location, count, two-strike, spray, and adjustability metrics.

Model design

Built to be inspectable.

The project connects large-scale pitch processing, transparent scoring, future-performance checks, and scouting presentation.
