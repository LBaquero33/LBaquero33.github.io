Computer vision / command review

CommandIQ

A coach-confirmed workflow for comparing a pre-pitch target with the pitch’s actual location.

Built with
Swift, Python, Supabase
Pitch data
TrackMan and Rapsodo-style CSVs
Output
Pitch review, saved sessions, and report export

Command review

Where was the target, and where did the pitch finish?

The catcher’s glove position before the pitch provides a useful reference for the intended target. CommandIQ keeps that reference beside the pitch’s measured result.

A coach can click the target manually or review an optional video-assisted suggestion. Either way, the target remains editable and must be confirmed before it is applied.

Actual horizontal and vertical locations come from the imported pitch data. CommandIQ does not claim to infer the pitcher’s true intent.

Review frame

The glove target stays reviewable.

The marked point is a coach-reviewed intended target. Plate and strike-zone calibration are also reviewed before pixel locations are converted into baseball measurements.

Workflow

What the system does—and what the coach confirms

  • ImportReads supported pitch type, velocity, and actual-location columns from TrackMan or Rapsodo-style exports.
  • Mark the targetAccepts a manual video click or an optional computer-vision suggestion. Manual entry remains available.
  • Confirm calibrationPlate and strike-zone proposals remain editable and are never applied automatically.
  • Review executionCompares the confirmed target with actual pitch location and keeps the evidence with the session.

Current status: the macOS workflow and service layer have been tested. Computer-vision suggestions are optional and can fall back safely to manual target entry.
