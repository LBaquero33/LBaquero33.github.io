The project

Command needs context.

CommandIQ is built to review where a pitcher intended to throw and what actually happened on each pitch.

The workflow supports intended-target entry, multi-pitch review, and video-assisted suggestions that remain subject to user confirmation.

Session history, cloud persistence, and report export carry the review beyond a single bullpen.

Workflow

Built around the review process.

The product keeps pitch data, intended location, video evidence, and saved results in one continuous workflow.

01

Set the target

Record intended location so command is evaluated against the plan for the pitch.

02

Review the pitch

Combine pitch-level data with computer-vision assistance and user confirmation.

03

Keep the record

Store sessions, revisit pitch history, and export a report for continued development work.
